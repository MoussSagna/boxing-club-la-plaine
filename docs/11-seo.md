## Principes

## Chaque page
Doit définir :
- title
- meta description
- canonical si nécessaire
- Open Graph
- image sociale

## Structured data
Évaluer l'utilisation de données structurées adaptées à un club / organisation locale.

## Technique
Prévoir :
- sitemap
- robots.txt
- URLs propres
- headings cohérents
- alt text
- performances correctes

## Performance
SEO et performance doivent être traités ensemble :
- images optimisées
- lazy loading
- fonts maîtrisées
- JS limité
