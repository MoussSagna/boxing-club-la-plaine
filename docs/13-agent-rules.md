# Agent Rules

## Règle 1 — Lire avant de coder
Avant chaque sprint, lire :
- `00-project-context.md`
- `01-brand.md`
- `04-design-system.md`
- `05-animation-system.md`
- `12-sprints.md`
- `15-decisions-log.md`

## Règle 2 — Ne pas inventer
Ne jamais inventer :
- tarifs
- horaires
- noms
- résultats
- dates
- coordonnées

Utiliser `TODO`.

## Règle 3 — Préserver les décisions
Ne pas changer une décision validée sans raison documentée.

## Règle 4 — Qualité
Après chaque modification :
- TypeScript
- lint
- build
- console
- responsive

## Règle 5 — Responsive
Tout composant doit être pensé mobile et desktop.

## Règle 6 — Motion
GSAP pour les animations importantes.
Pas d'animation gratuite.

## Règle 7 — Design
Ne pas dériver vers :
- SaaS
- glassmorphism
- fitness générique
- UI corporate
- gradients excessifs

## Règle 8 — Code
Éviter `any`.
Éviter les composants monolithiques.
Extraire les composants complexes.

## Règle 9 — Documentation
Toute décision importante doit être ajoutée au decision log.

## Règle 10 — Validation
Ne pas considérer un sprint terminé sans critères de validation remplis.
