# Boxing Club de la Plaine — Contexte projet

## Vision
Refondre le site du Boxing Club de la Plaine (Paris 15) en une expérience digitale premium, immersive et éditoriale.

Le site doit raconter une institution de boxe parisienne, pas simplement présenter une salle de sport.

## Objectifs
- Présenter clairement le club et son histoire.
- Faire découvrir les pratiques.
- Faciliter l'accès au planning.
- Mettre en valeur les coachs.
- Valoriser les actualités et la vie du club.
- Convertir les visiteurs vers un cours d'essai ou une inscription.
- Construire une identité digitale cohérente avec le logo officiel.

## Positionnement
Sportif, authentique, parisien, historique, humain, exigeant et accessible.

## Direction artistique
Editorial sportif + photographie documentaire + affiches de boxe + brutalism maîtrisé + esthétique cinématique.

## Stack
React + Vite + TypeScript + Tailwind CSS + shadcn/ui + GSAP.

## Pages
/, /club, /cours, /planning, /coachs, /actualites, /inscription, /contact.

## Règle fondamentale
Chaque choix doit renforcer l'impression : « une institution de boxe parisienne avec une vraie histoire ».
